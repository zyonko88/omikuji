## 1. この大学の仕組み（ここが他大学と全然ちがう）

自治医科大学は、へき地・離島をふくむ地域医療を担う医師を育てるために、
**全都道府県が共同で設立した私立大学**です（栃木県下野市）。そのため入試の形が独特です。

| 項目 | 内容 |
|---|---|
| 選抜の単位 | **都道府県ごと**。全国一律の合格ラインではなく「その県の枠」を県内の受験生同士で争う |
| 出願先 | 大学ではなく、**出願する都道府県の担当課（県庁など）へ提出** |
| 出願できる県 | 原則、本人または保護者の居住地などによる**地区制限**あり。他県との併願は不可 |
| 学費 | 6年間の学費相当額（**約2,300万円**）を修学資金として全額貸与。入学時の納入金の準備も不要 |
| 返還免除 | 卒業後ただちに出身都道府県知事が指定する公立病院等に勤務し、貸与期間の**1.5倍（6年→9年）**勤務すれば返還免除。うち**半分はへき地等**の指定病院 |
| 義務年限 | 上記のとおり**原則9年間**。途中で辞めると修学資金を（利息を含めて）一括返還 |
| 寮 | 1〜6年生まで全寮制 |

> つまり「学費が実質かからないかわりに、卒業後9年間は出身県の指定する病院で働く」制度です。
> **この義務年限が最大の検討ポイント**で、途中離脱時の返還額は数千万円規模になります。
> 制度の細部（勤務先の決まり方、専門研修の扱いなど）は都道府県ごとに運用が違うので、
> 出願先の県の担当課に直接確認しておくことを強くおすすめします。

## 2. 2027年度入試の一番大きな変更点 ―「年内入試」の新設【確定】

自治医科大学は**2026年3月27日に公式発表**し、
**2027年度（令和9年度）入学者の選考から、一部の県で年内入試（総合型選抜・学校推薦型選抜）を導入**します。
自治医大の医学部はこれまで**一般選抜のみ**だったので、大きな方針転換です。

### 実施する県と募集人員【確定】

| 県 | 総合型選抜 | 学校推薦型選抜（公募制） |
|---|---|---|
| 栃木県 | 2名 | ― |
| 富山県 | 1名 | 1名 |
| 山梨県 | 2名 | ― |
| 山口県 | 2名 | ― |
| 佐賀県 | 2名 | ― |

**この5県以外の道府県は、2027年度も一般選抜のみ**です。
また、**この5県でも例年どおり1月末の一般選抜は実施**されます（年内入試は追加の入口）。

### 年内入試の選考内容【確定】

- 出願書類の審査（調査書、志願者評価書、活動報告書 など）
- **面接**（都道府県による面接 と 大学による面接）
- **基礎学力検査：数学・英語**（大学教育を受けるために必要な力をみる）
- 以上を**総合的に判断**して合格者を決定

### 年内入試の日程【確定（月旬単位）】

| 段階 | 時期 |
|---|---|
| 総合型選抜の出願 | 2026年**10月中旬** |
| 学校推薦型選抜の出願 | 2026年**11月上旬** |
| 基礎学力検査・面接試験 | 2026年**11月中旬** |
| 合格発表 | 2026年**12月上旬** |

### 出願資格の目安【要確認】

進学情報サイトの掲載では、**全体の学習成績の状況（評定平均）4.0以上**、
**活動報告書の提出**、**本人または保護者の地区制限**が条件として挙げられています。
正確な条件は募集要項の原本で確認してください。
なお、年内入試の合格者が専願扱い（入学確約）になるかどうかは、要項での確認が必要です。

> **日付の感覚として：**今日（2026年8月1日）時点で、総合型選抜の出願まで**あと約2か月半**です。
> 5県のいずれかを志望していて年内入試を狙うなら、要項の入手と書類（活動報告書・志願者評価書）の
> 準備を**今すぐ**始める必要があります。

## 3. 一般選抜（全都道府県で実施）

### 募集人員【見込み】

- 全都道府県から**各2〜3名ずつ、合計123名**
- 令和8（2026）年度は、臨時定員増23名が認められて **100名→123名**（**栃木県地域枠3名を含む**）
- 令和9（2027）年度も **123名の予定**とされています（臨時定員増は年度ごとの認可のため、要項で要確認）

### 選抜の流れ

```
【第1次試験】各都道府県の会場（県が指定）
   1日目：学力試験（マークシート式）
   2日目：面接試験　※学力試験の及第者のみが受験できる
        ↓ 第1次試験合格発表
【第2次試験】自治医科大学（栃木県下野市）
        学力試験（記述式）＋ 面接試験
        ↓ 最終合格発表
```

**1日目の学力試験に受からないと2日目の面接に進めない**のが特徴です（同じ「第1次試験」の中で2段構え）。

### 第1次試験の科目・配点【見込み：令和8年度の内容】

| 科目 | 範囲 | 時間 | 配点 |
|---|---|---|---|
| 数学 | 数I・数II・数III・数A・数B（数列）・数C（ベクトル、平面上の曲線と複素数平面） | 80分 | 25点 |
| 理科 | 物理・化学・生物から**2科目選択** | 80分 | 50点（各25点） |
| 外国語 | 英語コミュニケーションI・II・III、論理・表現I・II・III | 60分 | 25点 |
| 合計 | | | **100点** |

- すべて**マークシート式**。**国語・地歴公民はありません**。
- 1科目25問・25点＝**1問1点**の形式で、**時間に対して問題数が多い**のが自治医大の特徴です。
  難問を解ききる力より、**標準問題を高速で確実に処理する力**が問われます。

### 第2次試験の内容【見込み】

- **記述式の学力試験（英語・数学）**
- **面接**（個人面接に加えて、集団討論が課される形式が続いています）
- **小論文は2021年度に廃止**され、その後も実施されていません。

面接では、志望理由、**地域医療・へき地医療についての考え**、部活動や経験、
併願校の状況などが定番の質問です。**「9年間の義務年限を理解し、納得して志望しているか」**を
確認する場だと考えて準備してください。

### 日程【見込み：令和9年度の確定日は要項で確認】

2027年度の確定日程は、このメモの時点では確認できていません。**例年のパターン**は次のとおりです。

| 段階 | 令和8（2026）年度の実績 | 令和9（2027）年度の見込み |
|---|---|---|
| 出願期間 | 1月上旬〜中旬 | 2027年1月上旬〜中旬（1月5日〜1月20日という掲載あり） |
| 第1次試験・学力試験 | 2026年1月26日（月） | 2027年**1月下旬** |
| 第1次試験・面接試験 | 2026年1月27日（火） | 学力試験の翌日 |
| 第1次試験合格発表 | 2026年1月30日（金）13:00 | 1月末 |
| 第2次試験 | 2026年2月4日（水） | 2月上旬 |

> 私立医学部の一般入試としては**日程が最も早い部類**で、共通テスト直後に本番が来ます。
> また、**大学入学共通テストは使いません**（自治医大の独自試験のみ）。

## 4. 出願の手続き（ここを間違えやすい）

1. **募集要項・願書は「都道府県庁の担当課」または「大学」で入手**します。
   - 要項の中身は全都道府県共通です。
   - 県によっては郵送請求・メール請求・テレメールでの取り寄せに対応しています
     （例：広島県は県内受験者向けに無料配布）。
   - 令和9年度の要項は**2026年7月発行予定**とされています（令和8年度は前年8月上旬から頒布）。
2. **出願書類は大学ではなく、出願する都道府県の担当課へ提出**します。
3. **試験会場も各都道府県が指定**します（第1次試験）。

> 年内入試（総合型・学校推薦型）の書類一式は、**実施する県の県庁でのみ**頒布されます。
