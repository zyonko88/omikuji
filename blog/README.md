# 院長ブログ 週3回投稿システム

対象: https://www.8181118.com/director3/ (WordPress)

## 運用フロー

1. 週3回、スケジュール(Routine)がこのセッションを起動する
2. Claudeが記事の下書きを作成し、WordPressに **下書き(draft)** として保存する
3. Claudeがチャットで下書き内容を提示し「公開していいですか？」と確認する
4. ユーザーが「公開して」と返信したら、その下書きを公開する
5. 返信がない・修正指示がある場合は公開しない(修正して再確認)

## 事前準備(ユーザー側)

### 1. 実行環境のネットワーク許可
Claude Codeの環境設定(ネットワークアクセス)で `www.8181118.com` への
アクセスを許可する。許可されていないとプロキシが403で接続を拒否する。

### 2. WordPressアプリケーションパスワードの発行
wp-admin → ユーザー → プロフィール → アプリケーションパスワード で
「Claude」等の名前で新規発行する。通常のログインパスワードは
REST APIでは使えないため必須。発行したパスワードは環境変数
(シークレット)として環境設定に登録する:

- `WP_BASE=https://www.8181118.com/director3`
- `WP_USER=<ユーザー名>`
- `WP_APP_PASS=<アプリケーションパスワード>`

## スクリプト

`wp_post.sh` — WordPress REST API (`/wp-json/wp/v2/posts`) 経由で
下書き作成・公開を行う。詳細はスクリプト冒頭のコメントを参照。

## 記事作成の方針

- 歯科医療に関する内容のため、必ず院長の事前チェックを経てから公開する
- 過去記事のトーン(患者向けの平易な語り口)に合わせる
- 記事の元ネタ・テーマは運用開始時にユーザーと合意した方法で決める
