# 月・女性・ことば｜項目べつアーカイブ

Instagram [@nemurimajo](https://www.instagram.com/nemurimajo/) の全234投稿の音声文字起こしを、
**項目（テーマ）ごとに読みかえせる自分専用のアプリ**にしたものです。

## つかいかた

[`index.html`](index.html) をブラウザで開くだけです。
インターネットにつながっていなくても動きます（スマホに保存しても使えます）。

GitHub Pages を有効にしている場合は、`docs/nemurimajo.html` として同じものが公開されます。

### 4つのタブ

| タブ | できること |
|---|---|
| **項目から** | 10の項目カードから選んで、そのテーマの投稿だけを読む |
| **ぜんぶ** | 新しい順に129編を通しで見る |
| **さがす** | 本文のことばで全文検索（例：「境界線」「お金」「月」） |
| **しおり** | 気に入った投稿に挟んだしおりを一覧する |

しおりはブラウザの保存領域（localStorage）に残ります。同じブラウザで開けば次も残っています。
ただし**パソコンやブラウザが変わると引き継がれません**。

「項目から」の下にある **✦ おまかせの一編をひらく** は、その日の気分でランダムに1編を開きます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | **アプリ本体**（1ファイルで完結。これだけあれば動きます） |
| `build.py` | `source/` から `index.html` を組み立てるスクリプト |
| `source/nemurimajo_全投稿_文字起こし_1of4.md` 〜 `4of4.md` | 元の文字起こし（新しい順に4分割） |

## 作りなおすとき

文字起こしを直したり、項目の分け方を変えたりしたら、次を実行すると `index.html` が作りなおされます。

```bash
cd nemurimajo
python3 build.py
```

項目の名前・説明・振り分けのキーワードは `build.py` の先頭にある `THEMES` にまとまっています。
キーワードには重み（3 = その項目にしか出てこない語、1 = ヒント程度の語）がついていて、
いちばん点数の高い項目に投稿が入ります。

## 注意

- 文字起こしは Whisper による自動生成のため、**固有名詞などに誤りが含まれます**
  （例：「アダルトチルドレン」が「アダルトチルドレー」など）。
- このアプリは**自分用**です。`index.html` には `noindex` を入れてあります。
