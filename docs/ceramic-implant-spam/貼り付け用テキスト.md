## 【A】フォームの不具合を直す（「フォーム」タブ）

### A-1. 受診歴と性別の名前かぶりを直す

「フォーム」タブの中で `radio-872` を探すと **2か所** 見つかります。

そのうち、**選択肢が「初めて」「過去に受診したことがある…」になっているほう**
（＝上のほう、「吉本歯科医院での受診」の見出しの下）の名前だけを書き換えます。

| 直す前 | 直したあと |
|---|---|
| `[radio radio-872 ` … | `[radio radio-visit ` … |

**`radio-872` を `radio-visit` に変えるだけ**です。そのあとの選択肢の文字列は触りません。
下のほう（女性／男性）の `radio-872` は **そのまま**にしてください。

> これで、「初めて」と「男性」の両方が選べるようになります。
> 現在は同じ名前のせいで、あとから選んだほうしか残りません。

## 【B】メール本文を直す（「メール」タブ）

### B-1. 最小限の修正（これだけでOK）

「メール」タブの「メッセージ本文」の中で、次の2か所を直します。

**① この行を削除する**

```
郵便番号：[your-zip]
```

**② この行を書き換える**

| 直す前 | 直したあと |
|---|---|
| `住所：[menu-163][your-city][your-building]` | `都道府県：[menu-163]` |

> `[your-city]` `[your-building]` は、いまのフォームに存在しない項目です。
> Contact Form 7 は、対応する入力欄が無いタグをそのまま文字として出す仕様なので、
> `[your-zip]` のような文字がメールに出てしまっています。

**③ 受診歴の行を追加する**（A-1 をやった場合のみ）

`お名前:[your-name]` の行の **すぐ上** に、次の1行を足してください。

```
当院での受診：[radio-visit]
```

## 【C】クイズを足す（Turnstile を入れても止まらないとき）

「フォーム」タブの、**送信ボタン `[submit ...]` のすぐ上**に貼り付けます。

```
<p>機械による自動送信を防ぐための確認です。次の計算の答えを半角数字でご入力ください。<br />
[quiz quiz-149 "1 + 3 = ?|4" "2 + 5 = ?|7" "6 - 2 = ?|4" "3 + 4 = ?|7"]</p>
```

`"問題|答え"` を並べておくと、送信のたびにランダムで1問だけ出ます。

> これは最後の手段です。入力が1つ増えるぶん、途中でやめる患者さんが必ず出ます。
> Turnstile（手順書 第3章）で止まっているなら、入れないでください。
