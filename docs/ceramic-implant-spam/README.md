## 1. いま何が起きているか

届いているメールの中身が、それを全部説明しています。

| メールの記載 | 意味 |
|---|---|
| お名前：`VKuChpiYTAvToghcQ` | 人間ではなくプログラム（ボット）がランダム文字列を入れている |
| フリガナ：`efeTcevudhDyIuoiCYCf` | 同上 |
| 内容記入欄：`CdnkebRzTYUXidpyG` | 同上。日本語が1文字も無い |
| メール：`a.n.de.rson.isl.ini.e@gmail.com` | Gmail の「ドットを無視する」仕様を悪用した使い捨てアドレス。同一人物が `anderson.islinie@gmail.com` などいくらでも別アドレスに見せかけられる |
| 電話番号：`2993500112` | 実在しない番号 |
| 郵便番号：`[your-zip]` | **フォームの不具合**（→ 第5章） |

ボットは、フォームのページを開いて入力しているわけではありません。
**送信先のアドレス（`/wp-json/contact-form-7/…`）に直接データを投げつけている**だけです。
だから「入力欄を増やす」「必須項目を増やす」では止まりません。
必要なのは、**人間が操作したことを確認する仕組み**です。

## 2. 先に確認してほしいこと（いちばん実害が大きい点）

**「自動返信メール」が、スパマー宛に送られていないか。**

もし送られていると、`ceramic-implant.jp` から見ず知らずの Gmail アドレスへ、
1日何十通も勝手にメールが飛んでいることになります。
これが続くと迷惑メール報告が積み上がり、**医院からの正規のメールが
患者さんに届かなくなる**（迷惑メールフォルダ行きになる）おそれがあります。

### 確認手順

1. ブラウザで次のリンクを開く（WordPressにログインした状態で）
   👉 https://www.ceramic-implant.jp/wp-admin/admin.php?page=wpcf7&post=149&action=edit
2. 上部のタブ **「メール」** をクリック
3. 画面を下までスクロールし、**「メール (2)」** という見出しを探す
4. その見出しの横の **「メール (2) を使用」** にチェックが入っていたら、
   **自動返信が送られています**

### 対処（当面の応急処置）

第3章の Turnstile を入れるまでの間だけなら、
**「メール (2) を使用」のチェックを外して → 画面右上の「保存」** で止められます。

ただしこれをすると、**本物の患者さんにも「受け付けました」メールが届かなくなります**。
Turnstile を入れてスパムが止まったら、チェックを戻してください。

> 迷ったら「チェックを外さずに、先に第3章の Turnstile を入れる」でも構いません。
> Turnstile を入れればスパム判定された送信にはメールが一切送られなくなります。

## 3. 【最優先】Cloudflare Turnstile を入れる（無料・約10分）

Contact Form 7 の 6.1 には、Cloudflare Turnstile との連携機能が**最初から入っています**。
プラグインの追加インストールは不要です。

Turnstile は Google の reCAPTCHA と同じ役割ですが、
- **患者さんに画像クイズを解かせません**（ほとんどの場合、何も操作せず通過します）
- 完全無料、利用回数の制限なし
- 「私はロボットではありません」の四角が出るだけ

高齢の患者さんが多い医院のフォームには、こちらのほうが向いています。

### 手順A：Cloudflare でキーを2つ発行する

1. 👉 https://dash.cloudflare.com/sign-up でアカウントを作る
   （メールアドレスとパスワードだけ。クレジットカードは不要です）
2. 登録したメールアドレスに届く確認メールのリンクをクリック
3. ログイン後、👉 https://dash.cloudflare.com/?to=/:account/turnstile を開く
4. **「Add widget」**（または「ウィジェットを追加」）ボタンをクリック
5. 次のとおり入力する

   | 項目 | 入れる内容 |
   |---|---|
   | Widget name | `ceramic-implant お問い合わせ` （何でも可） |
   | Hostnames | `ceramic-implant.jp` と入力して Enter、続けて `www.ceramic-implant.jp` も追加 |
   | Widget Mode | **Managed** を選ぶ |

6. **「Create」** をクリック
7. **「Site Key」** と **「Secret Key」** が表示されます。
   この画面は開いたままにしておいてください（次で使います）

### 手順B：WordPress 側に貼り付ける

1. 👉 https://www.ceramic-implant.jp/wp-admin/admin.php?page=wpcf7-integration を開く
2. **「Cloudflare Turnstile」** の枠を探し、**「インテグレーションのセットアップ」** をクリック
3. **サイトキー** に Site Key、**シークレットキー** に Secret Key を貼り付ける
4. **「変更を保存」** をクリック

### 手順C：確認

1. 👉 https://www.ceramic-implant.jp/お問い合わせ/ を開く
   （ログアウトした状態、またはシークレットウィンドウで開いてください）
2. 送信ボタンの手前に Turnstile の四角が表示されていればOK
3. 実際に自分で1件送ってみて、`info@8181118.com` に届くことを確認する

> **フォームの編集は不要です。** Contact Form 7 は、キーを保存した時点で
> サイト内のすべてのフォームに自動でウィジェットを差し込みます。

**通常はここまでで、この種のスパムは止まります。**
1週間ほど様子を見て、それでも届くようなら第4章へ進んでください。

## 4. それでも止まらないときの追加策

### 4-1. NGワードを登録する（3分・コードなし）

Contact Form 7 は、WordPress 本体の「コメントで許可されない単語」のリストを
**フォーム送信にも適用します**（送信内容・送信元IP・ブラウザ情報が判定対象）。

1. 👉 https://www.ceramic-implant.jp/wp-admin/options-discussion.php を開く
2. 下にスクロールして **「コメントで許可されない単語」** の欄を探す
3. すでに入っている内容は消さずに、**改行して1行ずつ**追記する

```
a.n.de.rson
anderson.islinie
```

4. 画面下の **「変更を保存」** をクリック

> **注意**：ここに書いた語は、ブログのコメントにも適用されます。
> `anderson` のような短い一般的な語だけを書くと、本物の方まで弾いてしまいます。
> **必ず、上の例のようにドット入りの特徴的な文字列で登録**してください。
>
> 送信元のIPアドレスも同じ欄に書けますが、スパム業者はIPを次々変えるので、
> あまり効果は続きません。基本は Turnstile で止めるものと考えてください。

### 4-2. かんたんなクイズを1問足す（5分・コードなし）

1. 👉 https://www.ceramic-implant.jp/wp-admin/admin.php?page=wpcf7&post=149&action=edit を開く
2. 「フォーム」タブの中身の、**送信ボタン（`[submit …]`）のすぐ上**に、次を貼り付ける

```
<p class="quiz-check">機械による自動送信を防ぐための確認です。次の計算の答えを半角数字でご入力ください。<br />
[quiz quiz-149 "1 + 3 = ?|4" "2 + 5 = ?|7" "6 - 2 = ?|4"]</p>
```

3. 画面右上の **「保存」** をクリック

`"問題|答え"` を並べておくと、送信のたびにランダムで1問出ます。
答えは全角・半角やスペースの違いを無視して判定されます。

> **これは最後の手段にしてください。** 患者さんの入力が1つ増えるぶん、
> 途中でやめてしまう方が必ず出ます。Turnstile で止まっているなら不要です。
> 「香川県は何地方？」のような知識を問う形は、間違える方が出るので避けてください。

### 4-3. 日本語が1文字も無い送信を弾く（コードあり・効果は最大）

今回のスパムは、**本文・氏名に日本語が1文字も含まれていない**という共通点があります。
そこを機械的に弾くフィルタを、このフォルダの
[`japanese-required-filter.php`](japanese-required-filter.php) に用意しました。

**設置方法（プラグインを使う安全なやり方）**

1. WordPress 管理画面 → 左メニュー **「プラグイン」→「新規プラグインを追加」**
2. 検索欄に `WPCode` と入力
3. **「WPCode – Insert Headers and Footers + Custom Code Snippets」** の
   **「今すぐインストール」→「有効化」**
4. 左メニューに出てくる **「Code Snippets」→「+ Add Snippet」**
5. **「Add Your Custom Code (New Snippet)」** を選ぶ
6. Code Type を **「PHP Snippet」** にする
7. `japanese-required-filter.php` の**2行目以降**（`<?php` の行は**除く**）を貼り付ける
8. 右上のスイッチを **Active** にして **「Save Snippet」**

> **注意**：このフィルタは、**英語だけで書かれた正当なお問い合わせも弾きます**。
> 海外からの英語の問い合わせを受ける可能性があるなら、入れないでください。
> テーマの `functions.php` を直接編集する方法もありますが、
> テーマ更新で消えたりサイトが真っ白になったりするので、上記のプラグイン経由を推奨します。

### 4-4. Flamingo を入れて記録を残す（推奨）

スパム対策を入れると、必ず「**本物の患者さんまで弾いていないか**」が心配になります。
Flamingo（Contact Form 7 の作者による公式の記録プラグイン）を入れておくと、
**スパム判定された送信も含めて全件がWordPress内に残る**ので、後から確認できます。

1. 「プラグイン」→「新規プラグインを追加」→ `Flamingo` を検索
2. **「Flamingo」（作者：Takayuki Miyoshi）** をインストール → 有効化
3. 左メニュー **「Flamingo」→「受信メッセージ」** で一覧が見られます
4. 上部の **「スパム」** タブに、弾かれた送信が入ります

Turnstile を入れた直後の1〜2週間は、ここを時々のぞいて、
本物の問い合わせが混じっていないか確認してください。

## 5. 【スパムとは別】フォーム自体の不具合 2件

調査中に、スパムとは無関係な不具合が2つ見つかりました。
**どちらも患者さんの入力が実際に壊れています。**

### 5-1. 「受診歴」と「性別」が同じ入力欄になっている（要修正）

フォームの HTML を確認したところ、

- 「吉本歯科医院での受診（必須）」…… 初めて／過去に受診したことがある
- 「お困りの方の性別（必須）」…… 女性／男性

この**2つのラジオボタンが、どちらも `radio-872` という同じ名前**になっています。
ブラウザは同じ名前のラジオボタンを「ひとつの選択肢グループ」として扱うため、

> **患者さんが「初めて」を選んだあとに「男性」を選ぶと、「初めて」の選択が外れます。**

実際、今回届いたスパムメールにも**「受診」の行が1行もありません**。
本物の患者さんからのメールでも、受診歴が届いていないはずです。
（両方「必須」なので、患者さんが「なぜか送信できない」と感じている可能性もあります）

**直し方**

1. 👉 https://www.ceramic-implant.jp/wp-admin/admin.php?page=wpcf7&post=149&action=edit
2. 「フォーム」タブで `radio-872` を検索し、**2か所**あることを確認
3. **受診歴のほう**（選択肢が「初めて」「過去に受診…」の行）の名前を
   `radio-872` から **`radio-visit`** に書き換える
   （`[radio radio-872 ...]` → `[radio radio-visit ...]`）
4. 「メール」タブを開き、本文に受診歴の行を追加する
   例：`初めてかどうか：[radio-visit]`
5. 「保存」をクリック
6. ログアウトした状態でフォームを開き、両方を選べることを確認する

### 5-2. メール本文に `[your-zip]` などがそのまま出ている（要修正）

届くメールの

```
郵便番号：[your-zip]
住所：香川県[your-city][your-building]
```

これは、**メール本文のひな形に書かれている項目が、いまのフォームに存在しない**ために
起きています。Contact Form 7 は、対応する入力欄が無いタグをそのまま文字として出す仕様です。

いまのフォームには、都道府県を選ぶ欄（`menu-163`）はありますが、
**郵便番号・市区町村・建物名の欄はありません。**（過去に削除されたと思われます）

**直し方**

1. 👉 https://www.ceramic-implant.jp/wp-admin/admin.php?page=wpcf7&post=149&action=edit
2. **「メール」** タブをクリック
3. 「メッセージ本文」の中の
   - `郵便番号：[your-zip]` の行を**まるごと削除**
   - `住所：[menu-163][your-city][your-building]` を
     **`都道府県：[menu-163]`** に書き換える
4. **「メール (2)」（自動返信）にも同じ記述があれば、そちらも同様に直す**
5. 「保存」をクリック

## 6. やらないほうがいいこと

| やりがちなこと | なぜダメか |
|---|---|
| フォームを閉じてメールアドレスを直接書く | 患者さんの問い合わせ手段が減るうえ、アドレス収集ボットに拾われてもっと増える |
| Gmail 側でフィルタして自動削除する | 目に入らなくなるだけで、**送信自体は続く**。自動返信によるドメイン評価の低下も止まらない |
| reCAPTCHA v2（信号機や横断歩道を選ぶやつ）を入れる | 高齢の患者さんが解けずに離脱する。Turnstile なら不要 |
| 「必須項目を増やす」「入力欄を複雑にする」 | ボットはページを見ずに直接送っているので効果なし。困るのは患者さんだけ |
| 問い合わせフォームのURLを変える | 一時的に減るが、すぐ再発見される |

## 付録：外部（REST API）からの自動操作は現状できません

2026-08-18 に、アプリケーションパスワードを使って Claude 側から
フォーム設定を直接書き換えられないか試しましたが、**サーバー側の設定で不可能**でした。

### 何が起きているか

`ceramic-implant.jp` のサーバーは **Apache + PHP 7.4.33** で動いています。
この構成では、認証情報を運ぶ `Authorization` というヘッダーが、
**Apache から PHP に渡される前に捨てられてしまう**ことがあります。
そのため WordPress は「誰も認証していない」としか判断できません。

**検証結果**（これが決定的な証拠です）

| 送った資格情報 | サーバーの応答 |
|---|---|
| 正しいアプリケーションパスワード | `rest_not_logged_in` (401) |
| **でたらめな**ユーザー名・パスワード | `rest_not_logged_in` (401) ← **同じ** |

パスワードが間違っているなら `incorrect_password` という別の応答が返るはずです。
**でたらめな情報でも同じ応答**ということは、**認証情報がそもそも WordPress に
届いていない**ということです。パスワードの発行手順に問題はありません。

（Claude 側の通信経路の問題でないことは、別のテストサーバーに対して
同じ方法で認証が成功することを確認済みです）

### 将来、自動操作をしたくなった場合の直し方

サイトのルートにある `.htaccess` ファイルの先頭に、次の3行を足すと通るようになります。

```apache
<IfModule mod_rewrite.c>
SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1
</IfModule>
```

ただし、この作業には **FTP かレンタルサーバーのファイルマネージャー**が必要で、
**書き間違えるとサイト全体が表示されなくなります**（500エラー）。
今回のスパム対策だけが目的なら、管理画面での手作業のほうが早くて安全です。

サーバーの引っ越しや PHP のバージョンアップ（8.x 系）を行う機会があれば、
そのときに解消される可能性が高いです。
