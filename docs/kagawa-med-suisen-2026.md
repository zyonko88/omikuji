# 香川大学医学部医学科 学校推薦型選抜Ⅱ まとめ(2026年度=昨年度の要項ベース)

対象資料: 「2026年度 学校推薦型選抜Ⅱ 学生募集要項(大学入学共通テストを課する学校推薦型選抜)法学部・経済学部・医学部医学科」(www.kagawa-u.ac.jp/files/1217/5464/1454/2026.pdf)
※ 2027年度の要項は8月末公開予定。本まとめは昨年度の内容であり、**出願前に必ず新要項の原本で確認すること**。

---

## 1. 募集人員

| 区分 | 人数 |
|---|---|
| 学校推薦型選抜Ⅱ 合計 | **30名** |
| うち一般枠 | 24名 |
| うち地域枠(学校推薦) | 6名 |

## 2. 出願資格・要件(一般枠)

- 調査書の**全体の学習成績の状況(評定平均)4.0以上**(現役)
- 既卒(1浪)は**4.3以上**、または現役時に受験した共通テストの指定教科科目**合計得点率80%以上**
- 学校長の推薦が必要。推薦人数の上限:
  - **現役: 1校につき8名まで(香川県内の高校は10名まで)**
  - 既卒: 1校につき1名まで(香川県内の高校は10名まで)
- → **現役が構造的に有利な設計**

## 3. 地域枠(6名)の追加要件(すべて満たして入学を確約できる者)

1. **香川県内の高等学校を卒業した者/卒業見込みの者**
2. 香川大学実施の**「地域医療セミナー」を修了**していること(2024年度または2025年度実施分)
3. **「香川県医学生修学資金」の貸付け**を受けること
4. 卒業後、香川県が定める医療機関(県内の公立病院等)で**9年間医師として従事する意志**があること

※ 地域医療セミナーは事前参加が必須のため、地域枠を考えるなら**セミナーの開催・申込時期を最優先で確認**(例年、出願よりかなり前に実施)。

## 4. 選抜方法・配点

| 要素 | 内容 |
|---|---|
| 大学入学共通テスト | 6教科8科目(配点・満点は要項で要確認) |
| 小論文 | **300点**。小論文Ⅰ・Ⅱの2部構成で、**英語の文章を含む**出題 |
| 面接 | **150点** |
| 調査書 | 総合判定に使用 |

- 共通テスト・小論文・面接・調査書を**総合して判定**
- **総合点にかかわらず、面接の結果のみで不合格になることがある**(明記)

## 5. 日程(2026年度実績)

| 項目 | 日程 |
|---|---|
| 出願 | 11月上旬〜中旬(正確な日付は新要項で確認) |
| 試験日1日目 | **11月22日(土)** 小論文Ⅰ 9:00〜10:15/小論文Ⅱ 10:35〜11:50/面接 |
| 試験日2日目 | **11月23日(日)** 面接 |
| 地域枠のみ | 11月22日(土)に**香川県による面接**も実施 |
| 共通テスト | 1月(通常どおり受験) |
| 合格発表 | 共通テスト後・2月上旬〜中旬(正確な日付は新要項で確認) |

※ 不合格でも前期日程(2月25日)の受験に支障はない(推薦Ⅱは共テ後判定のため、前期と事実上併願できる)。

## 6. 夏子への戦略メモ

- **評定4.0以上が最初の関門**。1学期までの評定を担任に確認し、出願可否を8月中に判断する
- 小論文は**英語の文章を含む**300点。二次の英語対策(読解+記述)がそのまま活きるが、日本語で論述する練習は別途必要。秋に過去問形式で2〜3本添削を受ける
- 面接150点+面接での不合格規定あり。一般前期用の面接準備(なぜ医師か・なぜ香川か・地域医療)を前倒しで仕上げる
- 地域枠はセミナー修了が前提条件。修了していなければ2027年度は一般枠での推薦出願となる
- 推薦Ⅱは「11月の2日間+共テ」で完結し、**落ちても前期に再挑戦できる実質2回目の受験機会**。評定が届くなら出願しない理由は少ない

## 未確認事項(8月末の2027年度要項で必ず確認)

- 共通テストの科目別配点・満点(推薦Ⅱでの換算)
- 出願期間・合格発表の正確な日付
- 評定要件・推薦人数上限・地域枠要件の変更有無
- 地域医療セミナーの対象年度の更新
