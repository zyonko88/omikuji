# 吉本夏子 — 香川大学医学部医学科 現役合格戦略ノート

作成日: 2026年7月27日(高3夏スタート版)
方針: **国語は「古文・漢文で満点」を取りにいき、現代文は省エネ運用。** 英数理の主軸を崩さず、共テ配点の歪みを味方につける。

---

## 1. ゴールの数字(まずこれだけ頭に入れる)

香川大医学科・前期は **共通テスト700点 + 二次試験700点 = 1400点満点**。

| 項目 | 数字(2025年度・前期一般枠) |
|---|---|
| 合格最低点 | **999.1/1400(71.4%)** 内訳: 共テ518.2/700・二次407/700 |
| 合格者平均点 | 1046.7/1400(74.8%) |
| 合格最高点 | 1195.9/1400(85.4%) |
| 共テボーダー(素点) | 74〜81%(年度で変動) |
| 倍率 | 前期およそ3〜4倍/二段階選抜あり |
| 偏差値 | 65前後(国公立医学部では標準) |

**夏子の目標ライン: 共テ550/700(素点約78%)+ 二次450/700(64%)= 1000点超え。**
満点勝負ではない。「合格最低点+30点」を安定して出す設計にする。

## 2. 配点表と「香川大のクセ」

**共通テスト(1000点→700点に圧縮)**

| 科目 | 配点 | 素点からの扱い |
|---|---|---|
| 英語 | 100 | **半分に圧縮** |
| 国語 | **200** | **そのまま(重い!)** |
| 数学 | 100 | **半分に圧縮** |
| 理科 | **200** | そのまま(重い) |
| 地歴公民 | 100 | そのまま |

**二次試験(700点)**: 英語200・数学200・理科200(2科目)・面接100

クセのまとめ:
- 共テでは**英数の失敗はダメージ半減**、逆に**国語・理科の失敗は直撃**する
- 二次は英数理各200点なので、共テ英数のミスは二次で挽回できる
- つまり香川大対策とは実質 **「共テ国語・理科を落とさない設計」+「二次英数理の標準問題を完答する力」**

## 3. 国語戦略 — 古文漢文満点プラン(この戦略の核心)

共通テスト国語(90分・200点)の内訳:

| 大問 | 内容 | 配点 | 夏子の方針 |
|---|---|---|---|
| 第1問 | 論理的文章 | 45 | 省エネ(6割強でOK) |
| 第2問 | 文学的文章 | 45 | 省エネ(6割強でOK) |
| 第3問 | 実用的文章 | 20 | **ここは取る**(知識不要・グラフ資料系で対策の伸びが速い) |
| 第4問 | 古文 | **45** | **満点目標** |
| 第5問 | 漢文 | **45** | **満点目標** |

### 数字で見るこの戦略の強さ

- 古漢満点(90点)+ 現代文6割(66点)= **156/200(78%)** → 目標ラインに届く
- 古漢満点 + 現代文5割(55点)= 145/200(72.5%)→ それでも共テ全体78%は他科目で十分カバー圏
- **現代文が本番で崩れても古漢90点が下支えする。「国語が怖くない」状態を作ることが目的。**

古漢が満点を狙える理由: 現代文と違い**知識(単語・文法・句法)を入れれば入れた分だけ確実に点になる**分野で、共通テストの古漢は標準レベル。理系の満点戦略として合理的。

### 漢文(45点)— 最短で仕上がる。8月中に固める

1. 「漢文早覚え速答法」or「漢文ヤマのヤマ」を1冊決め、**句法約100個を8月中に3周**
2. 重要漢字(読み・意味)を同じ本で暗記
3. 9月から共テ形式の漢文だけを週2題。**返り点を打ちながら音読**する(白文に強くなる)
4. 11月以降は過去問・予想問題パックで毎回時間を計る(目標: **10分で解き切る**)

### 古文(45点)— 暗記→読解の順。9月末までに知識完成

1. 古文単語帳(「古文単語315」等)を**1日30語×毎日回して9月末までに全周3回**
2. 文法は助動詞(意味・接続・活用)と敬語(誰から誰への敬意)に絞って完成させる
3. 10月から共テ形式の古文を週2題。解いたら**全文を現代語訳と照らして音読**
4. 和歌の修辞(掛詞・序詞)と古文常識(月の異名・官位・生活)は直前期の頻出。11月に薄い常識本を1冊
5. 目標: **15分で解き切る**

### 現代文(110点)— 捨てないが、時間をかけない

- 週1〜2題だけ、解説の詳しい教材で「**根拠に線を引いて選択肢を切る**」型を固定する(言い過ぎ・本文にない・因果逆転の3パターンで切る)
- 第3問(実用的文章・20点)は資料読み取り中心で伸びが速い。**ここだけは満点を狙う**
- 本番の解く順番を固定: **漢文(10分)→古文(15分)→実用文(10分)→評論→小説**。得点源から確実に回収し、残り時間を現代文に全部使う

### 週間ルーティン(国語は1日30〜45分まで)

| 曜日 | メニュー |
|---|---|
| 毎日(寝る前15分) | 古文単語 or 漢文句法の暗記カード |
| 火・木 | 古文 or 漢文の共テ形式1題(30分) |
| 土 | 現代文1題+週の間違い直し |

## 4. 共テ目標点シミュレーション(夏子版)

| 科目 | 配点 | 目標 | メモ |
|---|---|---|---|
| 英語 | 100 | 85 | 圧縮されるので9割狙いで力まない |
| 国語 | 200 | **155** | 古漢90(満点)+現代文65 |
| 数学 | 100 | 85 | 圧縮あり。二次力があれば自然に取れる |
| 理科 | 200 | 170 | **圧縮なし。共テ専用対策を秋に必ず入れる** |
| 地歴公民 | 100 | 80 | 「2か月で仕上げる公共・倫理」を継続 |
| **合計** | **700** | **575** | 貯金付き。最低でも550を死守 |

※ 2025年度の合格者は共テ最低518.2。575が取れれば共テ時点で優位に立てる。

## 5. 二次試験対策(700点)

**英語(90分・大問3題)— 目標130/200**
- 約550語読解(設問も英語)+約900語読解(日本語設問)+**テーマ型自由英作文**
- 医療・社会文化系テーマが頻出。**英作文は「減点されない易しい英文」で書く**練習を9月から週1本、必ず添削を受ける

**数学(100分・大問4題)— 目標130/200**
- **数Ⅲ微積がほぼ毎年出題**。複素数平面・確率・数列が続く
- 難易度は標準。**捨て問はほぼ無く、計算力と完答力の勝負**。網羅系(Focus Gold/青チャート)→標準問題精講レベルで足りる。奇問対策は不要

**理科2科目 — 目標140/200**
- 標準レベル中心。重要問題集レベルを2周して過去問へ

**面接(100点)— 甘く見ない**
- 配点があるうえ、**総合点にかかわらず面接のみで不合格になり得る**と明記されている
- 「なぜ医師か」「なぜ香川大か」「地域医療をどう考えるか」を秋までに文章化し、学校で模擬面接を最低3回

**過去問**: 赤本5年分は必須、できれば10年分。出題形式が安定した大学なので過去問の効果が大きい。

## 6. 推薦Ⅱという現役生の特権(要検討)

- 学校推薦型選抜Ⅱ(共テを課す): **一般枠24名+地域枠6名**
- 出願資格は**評定平均4.0以上(現役)**。現役は1校8名まで出願可(香川県内高校は10名)
- 1浪には4.3以上などより厳しい条件 → **推薦は現役が構造的に有利**
- 評定が4.0以上あるなら11月の出願を強く検討。一般前期との併願で受験機会が2回になる
- 地域枠(前期9名・推薦6名)は卒後の県内勤務条件があるため、志望動機と合うかを親・先生と相談して判断

## 7. 年間スケジュール(2026年8月〜2027年3月)

| 時期 | やること |
|---|---|
| **8月** | 漢文句法100個を完成/古文単語回し始める/数Ⅲ・理科の全範囲修了/夏の共テ模試で現状把握 |
| **9月** | 古文の文法完成/英作文添削スタート/二次向け標準問題演習を本格化 |
| **10月** | 古文・漢文を共テ形式演習へ/二次過去問に着手(まず1年分で距離を測る) |
| **11月** | 推薦Ⅱ出願判断・出願/古文常識・和歌修辞を補強/共テ理科・公民の比重を上げる |
| **12月** | 共テシフト(予想問題パック)。国語は解く順番と時間配分を固定して毎回同じ手順で |
| **1月中旬** | **共通テスト本番** → 自己採点、ボーダーと照合して出願確定(崩れた場合はプランB) |
| **1月下旬〜2月** | 二次過去問を軸に英数理仕上げ+面接練習/**2月25日 前期試験** |
| **3月** | 前期発表。後期出願校の準備も1月のうちに済ませておく |

## 8. プランB(頭の片隅に置くだけ)

共テ自己採点で国語が崩れた場合に備え、**国語配点が軽い医学部**を出願候補にストックしておく:
- 東北大(国語比率 約4%)、新潟大(国語・社会を半分に圧縮)など
- 国公立は共テ後に出願先を決められる。「本命は香川、国語事故なら配点の軽い大学へスライド」の二段構えなら、本番で国語に呑まれない
