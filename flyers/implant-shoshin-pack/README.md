# インプラント初診パック 院内案内チラシ

院内で患者さんにお渡しして、カウンセラーが説明しながら
「インプラント初診パック」をご案内するためのA4チラシ（1枚・カラー）です。

- [`インプラント初診パック_案内チラシ.pdf`](インプラント初診パック_案内チラシ.pdf) — 印刷用PDF（A4縦・フチなし）
- [`flyer.html`](flyer.html) — 元データ（文言・色の修正はこちらを編集して再PDF化）
- [`preview.png`](preview.png) — 仕上がりプレビュー

## 内容の構成

1. セットで受けられる内容（5項目: カウンセリング／レントゲン／CT／口腔内診察・写真／院長の総合診断）
2. 料金 5,500円（税込）※通常40,000円の診断メニュー・支払い方法
3. こんな方におすすめです（チェックリスト5項目）
4. 安心して受けていただくために（当日治療しない／持ち帰って検討／治療を前提としない）
5. ご案内導線（受付・カウンセラーへ声かけ／電話／WEB予約）

## デザイン

- 吉本歯科医院のテーマカラー（テラコッタ #B5432E ほか）と再現ロゴを使用
  （`yoshimoto-implant/assets/logo.svg` と同じもの。正式ロゴデータを支給いただければ差し替え可能）
- 「通常40,000円→5,500円」の表記は、院内配布物は医療広告ガイドラインの規制対象外のため
  記載しています。**このチラシをWebに掲載したり院外で配布したりする場合は、
  割引表示を外す必要があります。**

## PDFの再生成方法

```bash
cd flyers/implant-shoshin-pack
/opt/pw-browsers/chromium --headless --disable-gpu --no-sandbox \
  --print-to-pdf="インプラント初診パック_案内チラシ.pdf" \
  --no-pdf-header-footer file://$PWD/flyer.html
```
