# グリストバニッシュPRO 飲食店様向けチラシ（ブラッシュアップ版）

A4・2ページの印刷用チラシです。元チラシ（ゴールド基調）を、
GRIST VANISHロゴのシアン（`#07AFE0`）を主役にした濃紺×シアンのトンマナへ再デザインしました。

| ファイル | 内容 |

## 主な改善点

- ゴールド基調 → ロゴのシアン基調（濃紺 `#0d2140` ＋シアン `#07AFE0` ＋淡いシアン地 `#EAF7FC`）へ全面置換
- 商品パウチ写真を背景除去（白抜き・透過）して幅70mmに拡大
- 元データで見切れていた裏面下部「お客様の声」3件（大手外食チェーン役員／大型スーパー店長／中華料理店オーナー）を全文復元
- 表面下部で他要素に隠れていた見出し「厨房の『困った』が、3つ消えます。」を復元
- 木下シェフ紹介を再構成（写真＋氏名・役職・沿革を上段、推薦コメント全文を下段）
- 改行で1〜2文字だけが次行に落ちる「孤立文字」を解消
- 両ページとも実測高さ297mm以内（1P: 288.1mm ／ 2P: 294.7mm）でオーバーフローなし

## 再生成方法

`チラシ_印刷用.html` をヘッドレスChromeでPDF化します。

```bash
chrome --headless --no-pdf-header-footer \
  --print-to-pdf=出力.pdf チラシ_印刷用.html
```

※ 和文フォントは Noto Sans CJK JP／Noto Serif CJK JP（Mac では
ヒラギノ角ゴ／ヒラギノ明朝が自動的に使われます）。
