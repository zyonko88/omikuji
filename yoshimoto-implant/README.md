# 吉本歯科医院 インプラント治療専用サイト

香川県高松市・吉本歯科医院のインプラント治療専用ランディングページです。
「香川の方が、インプラントを求めて吉本歯科医院の**インプラント初診パック**に申し込む」ことを目的に、
高級感・信頼感を重視し、ローカルSEO／AEO（AI検索）対策を施した1ページ構成で制作しています。

- ファイル本体：`index.html`（HTML/CSS/JS すべて内包・依存なし）
- フォント：Google Fonts（Noto Serif JP / Noto Sans JP / Cormorant Garamond）

---

## 1. 公開方法（GitHub Pages）

このフォルダを Web に載せるだけで公開できます。最終的には公式ドメイン
`https://www.8181118.com/implant/` などに配置する想定です。

ローカル確認：
```bash
cd yoshimoto-implant
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## 2. あとから差し替えるもの（重要）

### ① 写真
本文中の「写真プレースホルダー」は、グレー地に用途ラベルを表示しています。
`class="ph"` の要素を `<img>` に置き換えるだけで差し替えできます。必要な写真は以下：

| 場所 | 用途 | 推奨 |
|------|------|------|
| ヒーロー背景 | 院内 or 笑顔の口元イメージ | 横長・高解像度（2000px幅〜） |
| 治療法セクション ×3 | 単独インプラント／All-on-4／入れ歯比較 | 16:10 |
| 院長セクション | 院長 吉本彰夫 のポートレート | 4:5 縦 |
| 症例 ×3 | Before / After 各1枚 | 正方形 |
| アクセス | Googleマップ埋め込み or 外観写真 | 4:3 |
| OGP | SNSシェア用画像 → `assets/ogp.jpg` | 1200×630 |

差し替え例：
```html
<!-- 変更前 -->
<div class="ph" data-label="写真：All-on-4 イメージ" style="aspect-ratio:16/10"></div>
<!-- 変更後 -->
<img src="assets/allon4.jpg" alt="All-on-4によるインプラント治療" style="aspect-ratio:16/10;object-fit:cover;width:100%">
```

### ② ロゴ
`assets/logo.svg`（ヘッダー用・ダーク文字）と `assets/logo-light.svg`（フッター用・白抜き）は、
吉本歯科医院の実際のロゴ（テラコッタのエンブレム＋「吉本歯科医院／インプラントクリニック」）に
合わせて**再現**したものです。ピクセル単位で正確に合わせたい場合は、公式ロゴデータ
（AI/SVG/PNG）をこの2ファイルに差し替えてください。

### ③ イメージカラー（吉本歯科医院ブランドカラー適用済み）
公式のテーマカラー（テラコッタ／ブリックレッド）を適用しています。色を微調整したい場合は、
`index.html` 冒頭の `:root { ... }` にある **`--brand` 系4色**だけを変更すれば全体に反映されます。

```css
--brand:#B5432E;        /* メインカラー：テラコッタ（ロゴ・ボタン・見出し） */
--brand-deep:#8A3120;   /* 濃色（ホバー・グラデーション） */
--brand-darkest:#2C1A13;/* 最濃色（ヒーロー・フッター背景／木目を思わせる深いブラウン） */
--brand-soft:#F7ECE7;   /* 淡色背景 */
--gold:#C2A264;         /* サブアクセント（落ち着いた真鍮・高級感） */
--gold-deep:#9C7A38;
```
※メインはテラコッタ、背景の濃色部分は「木を基調とした高級感のある院内」に合わせた
　ウォームブラウンでまとめ、差し色に落ち着いた真鍮ゴールドを少量使用しています。

### ④ 初診パックの料金
「インプラント初診パック」の料金は `●●,●●●円（税込）` のプレースホルダー表記です。
確定金額に差し替えてください（`#pack` セクション内）。

### ⑤ 申込フォームの送信先
`#apply` のフォームは現在デモ動作（`handleApply`）です。公開前に、
予約システム・Googleフォーム・メール送信サービス（Formspree等）いずれかの送信先を設定してください。

## 4. SEO / AEO（AI検索）対策の内容

香川県の方が「香川 インプラント」等で検索・AI質問した際に吉本歯科医院へ辿り着くよう、以下を実装：

- **構造化データ（JSON-LD）**：`Dentist`（所在地・診療時間・対応地域・電話）、`MedicalProcedure`（インプラント）、`FAQPage`、`BreadcrumbList`
- **地域メタ**：`geo.region=JP-37`、`geo.placename=香川県高松市`、`areaServed`に高松市・さぬき市・東かがわ市など
- **AIクローラー許可**：`robots.txt` で GPTBot / ClaudeBot / PerplexityBot / OAI-SearchBot 等を明示的に許可
- **`sitemap.xml`**、canonical、OGP、セマンティックな見出し構造
- 本文に「香川」「高松」「屋島」「潟元」など地域語＋インプラント関連語を自然に配置

> 公開ドメインが `https://www.8181118.com/implant/` 以外になる場合は、
> `index.html` の canonical / OGP / JSON-LD の URL、`robots.txt`・`sitemap.xml` の URL を実ドメインに合わせて更新してください。

## 5. 構成について（ナタリーデンタルクリニックを参考）

ナタリーデンタルクリニック（[natalie-dent.com](https://www.natalie-dent.com/)）の構成・訴求の考え方を
お手本に、以下を吉本歯科医院向けに取り込んでいます。**文章は他院サイトの流用ではなく、
すべて書き下ろしのオリジナル**です（著作権・重複コンテンツ・医療広告ガイドライン対策）。

- 「悩み → 初診（申込の核）→ 選ばれる理由 → **安全へのこだわり** → 治療法 → **All-on-4専用** → 流れ → 院長 → 症例・声 → FAQ → アクセス → 申込」の導線
- **安全管理を前面に出す**構成（`#safety`）：CT精密診断／治療計画／全身状態への配慮／衛生・滅菌／説明と同意／メンテナンス・保証
- **All-on-4を独立セクションで訴求**（`#allon4`）：総入れ歯の方向け、即時荷重、院長のMalo研修

### ⚠️ 掲載前に事実確認が必要な項目（医療広告ガイドライン）
`#safety` セクションは、良質な歯科医院で一般的に行う内容で記載しています。もし吉本歯科医院で
以下のような**より高度な安全体制**を実施している場合は、事実に基づいて追記・強化してください。
逆に実施していない項目は削ってください（未実施の内容の記載は不可）。

- 麻酔科医（麻酔担当医）による全身管理／静脈内鎮静
- 術前の血液検査
- 無菌手術室・専用オペ室
- インプラントセーフティーマーク等の認定
- 保証制度の具体的な年数・条件
