# 母性型 365日メールマガジン

boseigata.com の読者に**毎朝1通**お届けする、365日分の原稿です。
50代以降の女性に向けて、すべての回が「**これが母性型です**」に着地する構成になっています。

## ファイル

| ファイル | 内容 |
|---|---|
| `days/` | **1日1ファイル**の原稿（`Day001_01月01日.md` 〜、全366通） |
| `件名一覧.md` | 366通の件名一覧表（Day・日付・件名・ファイルへのリンク） |
| `01月.md` 〜 `12月.md` | 同じ原稿を月ごとにまとめたもの（通して読むとき用） |
| `README.md` | この設計書 |

**中身は `days/` と `01月.md`〜`12月.md` で同じ**です。用途で使い分けてください。

- **配信システムに1通ずつ登録する** → `days/` を使う（1ファイル＝1通）
- **通して読む・書き直す** → 月ごとのファイルを使う
- **どの日に何を送るか確認する** → `件名一覧.md` を見る

## 1通の型

すべての回が同じ型でできています。読者は毎朝、同じリズムで受け取ります。

```
### Day ○○ ｜○月○日
**件名：**（開封したくなる一文）

おはようございます。

（本文 350〜450字）
　┗ ①情景・呼びかけ（読者の朝に寄り添う）
　┗ ②今日の気づき（本題）
　┗ ③言い切り（背中を押す一文）

**─ これが母性型です ─**
（母性型の定義に着地させる1〜2行）

**今日の小さな一歩**
（今日すぐできること1つ）
```

**なぜこの型なのか**

- **毎回「これが母性型です」で締める** → 365回くり返すことで、「母性型」という言葉が
  読者の中に自然に定着します。用語を説明しなくても伝わる状態を作ります
- **朝に読んで1分** → 通勤前・家事の合間でも読み切れる長さに揃えています
- **最後に一歩だけ置く** → 「読んで終わり」にせず、行動と言葉を一致させます
  （これ自体が母性型の実践です）

## 配信のしかた

### 毎朝の自動配信

お使いのメール配信システム（オートビズ・MyASP・エキスパなど）の
**ステップメール機能**に、Day 1 から順に登録します。

- 配信時刻は **朝5時〜6時** がおすすめです（起きたときに届いている状態になります）
- 「登録日から1日目、2日目…」と設定すれば、
  **いつ登録した読者でも Day 1 から順番に**受け取れます
- 日付（○月○日）は季節の話題を入れている回だけの目安なので、
  ステップメール運用なら気にせず順番どおりで問題ありません

### カレンダー配信にする場合

「全員に同じ日に同じ内容を届けたい」場合は、`01月.md` の Day 1 を1月1日に、
というように日付どおりに予約配信します。この場合、新しく登録した読者は
途中から読み始めることになります。

**ステップメール方式のほうがおすすめです。**
どの読者も「1日目」から順に受け取れて、話の流れが崩れないからです。

## 書き換えるときのポイント

原稿はそのまま使えますが、池田先生ご自身の言葉に寄せたい場合は、
次の3ヶ所だけ差し替えると、ぐっと「先生の声」になります。

1. **冒頭のあいさつ** — 「おはようございます。」の後に、
   その日の天気や季節のひとことを足す
2. **体験談** — 「以前、こんな受講生の方がいらっしゃいました」と
   実際のエピソードに差し替える（いちばん効きます）
3. **署名** — 各月ファイルの末尾にある署名欄を、正式なものに整える

## 注意

- 健康・食事に関する回（5月など）は、**断定を避けた書き方**にしています。
  医療行為をすすめる表現にはしていません
- 有料サービスへの勧誘は入れていません。**メール講座は信頼を育てる場**と位置づけ、
  売り込みは別途ご案内メールで行うことをおすすめします
