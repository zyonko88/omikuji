# boseigata.com ランディングページ（母性型思考）

池田弘子先生（株式会社人間科学研究所）の「母性型思考」1ページLPです。
もともと Google ドライブの `boseigata-site/index.html` に置いてあったものを
このリポジトリに移し、公開できる状態まで仕上げました。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | LP本体（1ページ完結・無料タイプ診断つき） |
| `privacy.html` | プライバシーポリシー |
| `tokushoho.html` | 特定商取引法に基づく表記 |

## ページの構成

1. ヒーロー（頑張るのをやめた瞬間、すべてがうまく回り始める）
2. 共感パート（こんなことを感じていませんか？）
3. 母性型思考とは
4. 自然の3つの法則（諸法無我／表裏一体／合わせ鏡）
5. 現実は「映写機」で変わる
6. **無料タイプ診断（全7問）** → 3タイプに分岐
7. 個人レッスン・セミナー（3プラン）
8. 受講者の声
9. プロフィール
10. 無料メールレッスン登録

## 診断のしくみ

7問すべて3択（A／B／C）で、選択の傾向から3タイプに分かれます。

| 条件 | 判定 |
|---|---|
| B が4つ以上 | 母性型モード |
| A が4つ以上 | ハードモード型 |
| それ以外 | バランス移行期 |

診断結果はフォームの隠しフィールド `diagnosis_type` に自動で入るので、
メール配信システム側でタイプ別にシナリオを分けることもできます。

## ⚠️ 公開前に必要な作業

### 1. メール講座の登録先を設定する（最重要）

`index.html` の下のほうにある、この行を書き換えてください。

```js
const OPTIN_ENDPOINT = ''; // ← ここに配信システムの送信先URLを貼り付け
```

お使いのメール配信システム（オートビズ、MyASP、エキスパなど）の
登録フォームの「送信先URL（action属性）」を `''` の中に貼り付けます。

**空のままだと、登録ボタンを押しても完了メッセージが出るだけで、
実際にはどこにも登録されません。**

### 2. 特定商取引法に基づく表記を埋める

`tokushoho.html` の赤字「※要記入」の項目を埋めてください。
**所在地・電話番号は法律上の必須項目**なので、空欄のままでは公開できません。

- 所在地／電話番号／メールアドレス
- お支払方法・お支払時期
- キャンセル・返金の条件

記入し終わったら、ページ上部の黄色い注意書き（`<div class="todo">`）を削除します。

### 3. プライバシーポリシーの連絡先を埋める

`privacy.html` の「※要記入」（お問い合わせ用メールアドレス）を埋めて、
同じく黄色い注意書きを削除してください。

### 4. 写真を入れる

現在は絵文字のプレースホルダーになっています。

- プロフィール写真：`.profile-avatar` の 🌸
- 本文イメージ：`.message-img` の 🌿
- SNSシェア用のOGP画像（1200×630px）：`<head>` 内のコメントアウトを外して差し替え

### 5. 掲載内容の最終確認

- **料金**（22,000円／5,500円／198,000円）が現在のものと合っているか
- **受講者の声**が実際にご本人の許可を得たものか
- プロフィールの「個人セッション累計500名以上」などの数字が正しいか

## 公開方法

WordPress（VKテーマ）で運用中の boseigata.com に載せる場合、
このHTMLは1枚完結なので、次のどちらかになります。

- **A：固定ページに貼る** — WordPressの「カスタムHTML」ブロックに `index.html` の
  `<body>` 内をそのまま貼り、`<style>` をカスタムCSSに移す
- **B：静的ファイルとして置く** — サーバーの `/lp/` などに3ファイルをアップロードして
  `https://www.boseigata.com/lp/` で公開する（WordPressと共存できます）

**B のほうが崩れにくく、おすすめです。**
どちらで進めるか決まりましたら、手順をご案内します。
