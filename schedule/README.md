## 日付を変えて刷り直す方法

1. `yoshimoto-todo-schedule.html` の該当行を書きかえる
   - 赤い期限日 … `<td class="due">8/14<span class="wd">（金）</span></td>` の数字
   - バーの位置 … 同じ行にある `<td class="wk">` は左から順に「8/3の週・8/10の週…10/26の週」の13列。
     バーを出したい列に `<span class="bar s"></span>`（開始）／`<span class="bar"></span>`（途中）／
     `<span class="bar e"></span>`（終了）を、◆を出したい列に `<span class="flag">◆</span>` を入れる
2. HTMLファイルをブラウザで開き、**Ctrl+P（Macは⌘+P）→ 用紙A4・縦・余白なし** で印刷
   - または Claude に「スケジュール表のPDFを作り直して」と頼めばPDFを再生成します
